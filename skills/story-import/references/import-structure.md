# 导入结构分流

仅 `story-import` 使用。字数阈值以 [length-routing.md](length-routing.md) 为准；本章处理章节结构、冲突和迁移路径。

Phase 1「基本信息确认」判定导入书走长篇还是短篇迁移。命中即停。

| 优先级 | 信号来源 | 判定规则 |
|--------|---------|---------|
| 1 | 用户显式声明 | 用户说「这是长篇 / 短篇」→ 以用户为准 |
| 2 | 结构信号 + 字数校验 | 明确章节分隔符且章节数 ≥ 5 → 长篇；全文无章节分隔、单文件单篇 → 按 length-routing 字数阈值表 |
| 3 | 字数兜底 | 仅在 1、2 均不明确时，按 length-routing 字数阈值表 |
| — | 冲突处理 | 信号矛盾时不自动决策，复述后请用户拍板 |

## 优先级 1：用户显式声明

Phase 1 向用户提问：**「这是长篇还是短篇？」**

- 明确回答 → 锁定类型，跳过后续检测。
- 未回答或「不确定」→ 进入优先级 2。

## 优先级 2：结构信号 + 字数校验

章节分隔符识别（与 [structure-mapping-long.md](structure-mapping-long.md) 共用）：

| 分隔符模式 | 示例 |
|-----------|------|
| `第X章` / `第X章 ` / `第X章：` / `第X章 XXX` | 第1章 初入江湖 |
| `Chapter X` | Chapter 1 |
| 纯数字编号 + 标题 | 1. 觉醒 |

| 检测结果 | 判定 |
|---------|------|
| 有明确章节分隔符，且章节数 ≥ 5 | 长篇 |
| 全文无章节分隔，单文件单篇，且总字数 < 20000 | 短篇 |
| 全文无章节分隔，单文件单篇，20000 ≤ 总字数 < 30000 | 短篇；复述时告知已超过 20000 建议上界 |
| 全文无章节分隔，单文件单篇，总字数 ≥ 30000 | 不自动判定，见「冲突处理」 |
| 有章节分隔符，但章节数 < 5 | 结构不明确 → 优先级 3 |
| 分隔符模式模糊（如仅有单个标题行） | 结构不明确 → 优先级 3 |

## 优先级 3：字数兜底

仅在优先级 1、2 无法给出明确判定时使用。

| 条件 | 判定 |
|------|------|
| 总字数 < 20000 且无章节结构 | 短篇 |
| 20000 ≤ 总字数 < 30000 且无章节结构 | 短篇，并告知超过建议上界 |
| 总字数 ≥ 30000 且无章节结构 | 请用户拍板 |
| 章节数 ≥ 5（任意字数） | 长篇 |
| 总字数 < 30000 但章节数 ≥ 5 | 初判长篇，须提示可能是分章短篇连载 |

> 20000 / 30000 是路由估算值，不同平台短篇上限有差异。执行时列入 open-questions，请用户复核。

## 分章短篇连载

总字数 < 30000 但章节数 ≥ 5 时提示：

> 「检测到分章结构（共 {N} 章），但总字数约 {X} 字，低于 30000 字。可能是分章短篇连载。确认按长篇导入，还是按短篇处理？」

用户拍板后锁定类型。

## 冲突处理

不同信号矛盾时**不自动决策**，回到 Phase 1 复述：

| 典型冲突 | 处理 |
|---------|------|
| 用户说「短篇」但检测到 20 章 | 复述章节结构，请用户确认是否仍按短篇 |
| 用户说「长篇」但全文无章节分隔且字数 < 20000 | 复述短篇信号，请用户确认是否仍按长篇 |
| 用户未声明、无章节分隔、单篇、字数 ≥ 30000 | 请用户在长篇工程 / 短篇工程之间选择 |
| 结构信号与字数方向相反 | 展示两项信号，请用户决定 |

拍板结果记入 Phase 1 上下文，后续不再重新判定。

## 判定结果与后续路径

| 判定结果 | 迁移路径 | 映射规则 |
|---------|---------|---------|
| 长篇 | Phase 3-L | [structure-mapping-long.md](structure-mapping-long.md) |
| 短篇 | Phase 3-S | [structure-mapping-short.md](structure-mapping-short.md) |

## 快速判定流程

```
Phase 1 问用户：「长篇还是短篇？」
         │
         ├─ 用户明确回答 ──────────────────────────► 锁定类型
         │
         └─ 未回答 / 不确定
                  │
                  ▼
         检测章节分隔符
                  │
                  ├─ 有分隔符且章节数 ≥ 5 ──────────► 长篇
                  │
                  ├─ 无分隔符，单篇，< 20000 ──────► 短篇
                  │
                  ├─ 无分隔符，单篇，20000 ≤ 字数 < 30000 ─► 短篇（告知超出建议上界）
                  │
                  ├─ 无分隔符，单篇，≥ 30000 ──────► 请用户裁定
                  │
                  └─ 信号不明确 → 按字数阈值表兜底
```
